# 围剿

网页贪吃蛇，1 打 3。

你是一条没有天赋的普通蛇。对面三条各有各的活儿：一条先抢食长个，长完了拿自己围你；一条贴着你走，走哪凉哪；一条满地图开传送门，把队友往你前面送。杀掉一条夺一枚碎片，集齐三枚化龙，判赢；三条全灭也算赢。

`dist/` 里四个文件放同一目录，双击 `index.html` 就开玩。一局通常一百多个转弯就分胜负，不用起服务也不用联网。

```
dist/
├── index.html     504 KB，游戏本体
├── pilot-w.js     2.8 MB，Q 键接管用的
├── echo-w.js      2.8 MB，残响蛇自己的脑子
└── duel-w.js      2.8 MB，残响蛇二阶段替玩家打的那份
```

## 键位

```
方向键 / WASD      转向
空格               霜爆    得先杀霜垠蛇，拿到元素碎片
F                  虚化    得先杀门枢蛇，拿到空间碎片
Q                  AI 接管，再按一次交还
H                  玩法说明
Esc                返回
```

## 规则

场地 56×42，四周是墙。开局位置每局重抽，但玩家只在中部 28%~72% 那块抽，猎手落在你外围一圈，彼此隔开九格以上。

玩家 5 节起，吃食物变长。三条猎手：

跑得最快的那条叫噬时蛇，开局 4 节，速度 6.0。前期它只顾着吃，吃得越多越长，但每多一节慢 4.5%，最多慢到一半。长到 10 节就翻脸，不再贪吃，改用身体堵你前头，还会借门枢蛇的门绕到你前面去。

霜垠蛇永远是 5 节，不进食也长不大。它身上每一节都在发霜，半径 3，贴身让你慢 34%，离远了衰减到 25%。你尾巴扫进去一样中招，探头吃一口再缩回去那套偷法没用。它自己不减速，猎手之间互相减速只会让整队看起来笨手笨脚。

门枢蛇 7 节，每 9 秒开一对门。前三次是排好的：先把霜垠送到你侧翼（不许开在你正前方，开场有扇门怼脸等于逼你自己走进去），再给噬时开在食物最密的地方催长，最后在你正前方和噬时正前方各开一端，让长身体一次横跨过来。三拍演完就自由发挥，按「跨墙抄近路 > 堵退路 > 附近有食物」打分挑点。门是双向的，谁都能走。

三条猎手撞到彼此不会死，只撞懵半秒。噬时蛇还顺带掉一节，霜垠和门枢不掉：它们不进食，掉了就再也补不回来，恒 5 会悄悄变成 4，连头对头的胜负门槛都跟着变。让它们互撞致死更糟，开局几十秒就能在中间挤成一团自己撞死，你什么都不用干白捡三个碎片。

本来想让三条蛇配合着出死局，实际跑下来只有门枢蛇加一条长成的噬时蛇这一条路成立，另外两条凑不出配合。

### 碎片

霜爆（空格，CD 12 秒）：以自己为圆心 5 格炸开，命中减速 50% 持续 1.5 秒，地上留半径 3 的霜痕 3 秒，踩上去再减 30%。

虚化（F，CD 14 秒）：1.2 秒内穿墙、穿蛇身，代价掉一节。落点压在墙里或者别人身上就相位坍缩，直接死。它不无敌。

时胀（被动）：永久 +12% 速度。

### 残响蛇

最后一条猎手不会就这么被打死，是原地蜕变。一阶段狂化：长度凭空多两节，速度 7.8，埋头狂吃，吃到「蜕变那一刻你的长度 + 1」为止。二阶段速度降到 6.0，霜域没了，但留着门，走位交给模型。

它身上不掉碎片，所以化龙不是「集满三枚」，是把三条都真的拆掉。化龙有 3.6 秒演出，期间无敌加 60% 加速。

## 三段 AI

Q 键接管用的那套，是个 54 万参数的小 CNN。输入是 12×21×21 的局部视野、5×14×14 的通道图，再加几十维标量特征，输出 9 个动作加一个价值。

三份权重结构一样，用途不同：

| 文件 | 谁在用 | 训练 | 评测 |
|---|---|---|---|
| `pilot-w.js` | Q 键接管，混战和三猎手阶段 | 150 万步 stage C | 72.7% |
| `duel-w.js` | 残响蛇二阶段，替玩家打 | 50 万步 stage F | 95.8% 单挑胜率 |
| `echo-w.js` | 残响蛇二阶段，它自己的脑子 | 100 万步 stage E | 93.8% |

按 Q 之后不用管，它自己判断该用哪份：场上还是三猎手就用 `pilot-w.js`，残响蛇进二阶段自动换成 `duel-w.js`。原来的模型在单挑里其实能打，只是换一套专门练过的更稳。

都是 PPO 练的。训练对手一半是脚本、一半是旧模型自己，不这么混的话它会训出只克规则的偏方。`duel-w.js` 是拿混战那份热启动的，只补单挑这一课。

缺文件不会崩：`pilot-w.js` 缺了按 Q 没反应，`echo-w.js` 缺了残响蛇退回脚本大脑，`duel-w.js` 缺了单挑时它还用混战那套走法，会明显变弱但不报错。

训练代码在 `train/`，没跟着这个目录走。

## 代码

内核 16 个模块在 `../snake-arena/src/js/`，围剿自己加的 13 个在 `src/js/`。构建就是把两边按文件名字符串排一遍拼成一个 HTML，编号即执行顺序。

这份仓库里只有围剿自己的 13 个，内核没带过来（`dist/index.html` 已经是拼好的，能直接玩）。想改代码得把 `snake-arena` 也放到上一级目录，否则 `build.mjs` 找不到源文件。

| 文件 | 干什么 |
|---|---|
| `05-siege-config.js` | 改 CFG 尺寸，加 4 条蛇、`MODES.siege`、围场 |
| `25-siege-map.js` | 56×42 的 ASCII 蓝图加保底出生位 |
| `45-siege-brain.js` | 三条猎手的职能 AI，门也在这 |
| `55-siege-rules.js` | 胜负、霜域、碎片、化龙、恒定长度、掉速 |
| `58-siege-skills.js` | 霜爆和虚化 |
| `86-siege-ui.js` | 出征屏、HUD、结算 |
| `88-siege-render.js` | 皮肤、霜域光环、门、过门断线 |
| `91~93-*.js` | 网络前向、观测编码、Q 键接管 |
| `95-siege-main.js` | 启动接管 |
| `96-echo.js` | 残响蛇的蜕变和两个阶段 |
| `97-echo-pilot.js` | 残响蛇二阶段的模型驱动 |

`05-` 必须排在 `10-util` 前面。`20-world.js` 的出生表和 `40-ai.js` 的静态数组都是模块顶层按 `CFG.W/H` 直接开出来的，尺寸晚改一步就白改。

构建：

```bash
cd snake-siege && node build.mjs
```

出 `dist/index.html`，同时往上一级也写一份同名 HTML。三份 `*-w.js` 是外挂的，构建只负责拷贝，换权重不用重建 HTML。

## 几个坑

改数值全在 `05-siege-config.js` 的 `SIEGE` 表。改地图是 `25-siege-map.js` 里 56 行 ASCII。

猎手 AI 有几处看着对、实际完全没方向。我踩过的：

距离场得从目标出发算。从自己出发的话 `dist[自己]=0`、四邻全是 1，`curD - dist[邻居]` 对四个方向是同一个常数，梯度等于不存在。

自己那格在 `blockedGrid` 里恒为 -1（被自己的身体标掉了），不能拿它当基准，一减整项就废。基准取四个邻居里最远的那个。

开阔地的权重必须比梯度小。之前是 5.88 : 1.6 倒挂，猎手会为了找空地背离职责目标，看起来就是在绕大圈。

猎手不能踏入玩家的身体格，包括马上要让出来的尾格。单看很合理，但玩家同一帧吃到食物 `grow > 0`、尾巴就不让了，猎手一头撞死在自己以为的空位上。

传送门是逐节迁移不是瞬移，`body[]` 会有一半在入口一半在出口的分裂状态，`trace()` 直接拉出一条横穿全图的长线。`88-siege-render.js` 按相邻点距离切开分段画，断口补个小环。

门的两头长得一样，看不出哪扇通哪扇。想做成一实心一空心。
